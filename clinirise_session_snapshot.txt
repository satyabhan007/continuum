| Area | GCP feature | How it satisfies DPDP (and HIPAA) | Implementation notes |

#### Step‑by‑step DPDP checklist before go‑live
1. Verify **no resources** outside `asia‑south1` (`gcloud asset list --filter="location!=asia-south1"`).
2. (Optional) Enable CMEK for Firestore & GKE disks.
3. Export IAM bindings and ensure least‑privilege.
4. Confirm audit‑log sink to a **locked** Cloud Storage bucket.
5. Confirm VPC‑SC perimeter includes all services.
6. Test consent flow – data is stored only after consent flag.
7. Test DSR endpoint – records removed from Firestore & Qdrant, operation logged.
8. Verify backup restore of Firestore snapshot.
9. Run Container Analysis on Cloud Run image – no critical findings.
10. Ensure BAA is signed in the console for HIPAA coverage.
